在仓库根目录执行截图脚本。脚本每次先等待回车，再明确倒计时 5 秒；倒计时期间打开并保持对应界面。原始整屏截图存入脚本输出的 `/tmp/headroom-m0-captures.*` 临时目录，之后由 Codex 检查并裁成上表的四张最终文件：

```bash
Scripts/capture_m0_baselines.sh
```

脚本不会弹出拖拽选区。每次按回车后会显示 5 秒倒计时；倒计时结束时自动截取整个屏幕并保存。四个场景依次这样准备：

1. 官方账号卡：按回车后点击菜单栏 Headroom 图标，进入 `Codex` 页，让 `官方账号` 分组中的一张账号卡完整可见并保持不动。
2. API 卡：关闭上一次弹层并回到终端，按回车后重新打开 Headroom 的 `Codex` 页，滚动到中转/API 卡并让整张卡完整可见。
3. 菜单栏弹层：关闭上一次弹层并回到终端，按回车后重新点击 Headroom 图标，保持整个弹层的当前可见边界不被其他窗口遮挡。这里的“完整”指从弹层顶部边缘到弹层底部边缘都出现在整屏截图中，不是只截某一张卡；滚动区域中尚未显示的内容不需要拼接成长图。
4. 设置页：在这一轮按回车前，先从 Headroom 弹层底部选择 `设置…` 打开设置窗口，再回到终端按回车；倒计时期间只需把设置窗口点到前台，并保持窗口及标题栏完整可见。

脚本最后打印原始截图目录。不要移动或重命名原始文件；Codex 会从该临时目录读取、检查并裁剪到最终文件名。

